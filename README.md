# 르샤인 두피센터 CRM 두피진단 VER.2.1

`르샤인 두피진단 UI/UX 개발 명세 ver.2.1`을 기준으로 구현한 로컬 HTML 프로토타입입니다. 별도 패키지 설치 없이 동작합니다.

## 실행

이 폴더에서 터미널을 열고 다음 명령을 실행합니다.

```bash
python3 -m http.server 4173
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다.

## 빠른 체험

1. `두피 진단 시작`을 누릅니다.
2. `합성 샘플 3장 불러오기`를 누릅니다.
3. `데모 분석 시작`을 누릅니다.
4. 현재 단계, 민감성·각질·유분, 악화 흐름, 건강 비교, 권고 치료를 확인합니다.
5. 단계 변경 시 수정 사유를 입력하고 `의료진 결과 확정`을 누릅니다.
6. `상담 인계`를 누릅니다.

## 구현 범위

- 사진 1~6장 업로드·삭제·대표 지정·순서 변경
- 환자 결과 단계 `2`, `2+`, `3`, `3+`, `4` 제한
- 전체 교육용 단계 `0`~`4+` 표시
- 환자 종합 점수 제거
- 민감성·각질·유분별 1~30 데모 점수와 사진·설명
- 현재 → 다음 단계 → 4+단계 악화 흐름
- 건강한 두피 VS 4+단계 비교
- 단계별 필수 치료와 강화 치료 매핑
- 의료진 수정 사유·확정·상담 인계
- 사례 A/B 레이아웃과 데스크톱·모바일 반응형

## 데모 경계

- 이미지 내용을 판독하는 의료 AI는 연결되어 있지 않습니다.
- 단계와 세부 점수는 로컬 데모 규칙으로 한 번 생성되며 화면 재렌더링 중에는 유지됩니다.
- 4+단계, 2~4개월 진행 기간, 모발 굵기·모근당 모발 수, 치료 횟수는 환자 노출 전 의료진 검수가 필요합니다.
- 사례 A/B는 동일 환자의 치료 전후 결과가 아닌 UI 시뮬레이션입니다.

## 사진과 개인정보

- 업로드 사진은 브라우저 메모리에서만 사용하며 서버·브라우저 저장소에 보관하지 않습니다.
- 새로고침하거나 창을 닫으면 업로드 상태가 사라집니다.
- 실제 환자 사진 대신 합성·가명 테스트 이미지를 사용하십시오.
- 지원 형식은 JPG, PNG, WEBP이고 장당 최대 크기는 10MB입니다.

## 프로덕션 연결 전 필수 작업

- 서버 인증과 관리자·의료진·상담실장 역할별 권한 검사
- 공개되지 않은 이미지 저장소와 짧게 만료되는 미리보기 주소
- 실제 AI 분석 API, 모델 버전, 실패 처리와 분석 로그
- 의료진 승인 기준표와 버전 관리
- 환자 촬영·분석·사례 활용 동의 관리
- 진단 세션 저장·복구, 확정 변경 이력과 감사 로그
- 파일 형식·용량의 서버 재검증

## 자동 검증

로컬 서버를 실행한 상태에서 Playwright가 설치된 Node.js 환경으로 다음 파일을 실행합니다.

```bash
node qa-smoke.cjs
```

검증 항목에는 금지 단계 미노출, 종합 점수 제거, 세부 점수 범위, 치료 매핑, 확정·인계, 모바일 가로 넘침이 포함됩니다.
