# 르샤인 두피센터 CRM 두피진단 VER.4.1

최종 기획서의 `사진 등록 → 품질 확인 → 자동 단계 판정 → 화면 3·4·5 → 상담 인계` 흐름을 구현한 독립 실행형 로컬 웹앱입니다. 정상 건은 필수 의료진 확정 없이 결과로 이동하며, 의료진 화면은 낮은 신뢰도·단계와 소견 불일치 건의 예외 검토로만 사용합니다.

## 실행

별도 설치 없이 실행됩니다.

```bash
cd "이 폴더 경로"
python3 -m http.server 4173 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다.

`index.html`을 직접 열어도 기본 기능은 동작하지만, 브라우저 보안 정책 차이를 피하려면 위 로컬 서버 방식을 권장합니다.

## 구현 범위

1. 두피 사진 1~6장 등록
2. JPG·PNG·WEBP 형식 및 장당 10MB 제한
3. 대표 사진 지정, 순서 변경, 삭제
4. 촬영 부위·장비·배율 메타데이터
5. 합성 0~4단계 자동 결과와 예외 검토
6. 숫자 점수 대신 붉은기·각질·유분의 정성 등급
7. VER.4.1 결과 5개 화면
   - 진단 요약
   - 심각성 근거
   - 현재 단계별 진행 경로
   - 치료 계획·완료 기준
   - 내부 상담 가이드
8. 모발 굵기·모근당 모발 수 승인 전 잠금 표시
9. 결과 인쇄, 의료진 상담 연결, 상담실장 인계
10. 메모리 내 작업 로그
11. 데스크톱·태블릿·모바일 반응형 UI

## 파일 구조

```text
index.html        화면 구조
styles.css        전체 UI 및 반응형·인쇄 스타일
app.js            진단 흐름과 화면 상호작용
assets/           합성 QA 이미지
qa-smoke.cjs      Playwright 설치 환경용 선택적 자동 점검
SECURITY.md       운영 연결 전 보안 요구사항
```

## 중요한 경계

- 현재 버전은 제품·상담 흐름 검증용 로컬 프로토타입입니다.
- 실제 의료 AI 모델, CRM 서버, 사용자 로그인, 데이터베이스와 연결되어 있지 않습니다.
- 분석 단계·관찰값·치료 계획은 합성 데모이며 실제 진단이나 치료 권고가 아닙니다.
- 일반 사진의 내용·초점·조도·두피 노출을 실제 AI로 판독하지 않습니다. 형식·용량만 브라우저에서 확인합니다.
- 업로드 사진은 브라우저 임시 메모리에서만 사용하며 서버·`localStorage`·`IndexedDB`에 저장하지 않습니다.
- 새로고침 또는 창 종료 시 사진과 진단 내용이 사라집니다.
- 실제 환자 사진 대신 가명·합성 테스트 이미지만 사용하십시오.

## 운영 버전 전환 시 필수

- 서버 측 로그인·역할 권한 검사(의료진/상담실장/관리자)
- 비공개 이미지 저장소와 만료형 접근 URL
- 환자 촬영·분석·사례 활용 동의 관리
- 의료진 승인 기준표 및 상담 문구 버전 관리
- 실제 AI 모델 버전·입력·출력·의료진 수정 이력 감사 로그
- 진단 세션 저장·복구 및 삭제 정책
- 파일 악성코드 검사, 업로드 MIME 재검증, 크기 제한
- 개인정보 마스킹과 최소 보관 원칙
