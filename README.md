# 르샤인 두피센터 CRM 두피진단 VER.2.1

원장 선정 단계별 두피 사진 39장을 기준으로 0~4+ 단계를 제안하는 브라우저 기반 프로토타입입니다. 별도 패키지 설치 없이 동작합니다.

## 실행

```bash
python3 -m http.server 4173
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다.

## 사용 순서

1. `두피 진단 시작`을 누릅니다.
2. 환자 두피 사진을 1~6장 등록합니다.
3. `39장 기준 분석 시작`을 누릅니다.
4. 제안 단계와 민감성·각질·유분, 악화 흐름, 권고 치료를 확인합니다.
5. 의료진이 단계를 검토·확정한 뒤 상담실장에게 인계합니다.

`원장 선정 참고사진 3장 불러오기`는 환자 사진 없이 화면을 확인하기 위한 QA 기능입니다.

## 판별 구조

- 원장 선정 39장 전체에서 붉은기, 각질·밝은 영역, 노란 부착물, 색 분포, 밝기, 질감 특징을 추출합니다.
- 새 사진과 39장의 특징 거리를 브라우저에서 계산하고 가까운 5개 참고사례로 단계를 제안합니다.
- 0단계 비교를 위해 기존 건강 두피 기준 1장을 추가해 총 40개 특징 벡터를 사용합니다.
- 단계별 대표 사진 8장은 39장 중 원장 선정 1순위 사진이며 EXIF 메타데이터를 제거해 화면에 표시합니다.
- 환자 업로드 사진은 브라우저 메모리에서만 분석되며 서버로 전송하거나 저장하지 않습니다.

## 구현 범위

- 사진 1~6장 업로드·삭제·대표 지정·순서 변경
- 0·1·1+·2·2+·3·3+·4·4+ 9개 결과 단계 제안
- 단계별 서로 다른 대표 사진과 원장 정의 증상 설명
- 민감성·각질·유분 1~30 보조 점수
- 현재 → 다음 단계는 2~4개월, 다음 단계 → 4+는 남은 단계별 2~4개월을 누적한 악화 흐름
- 단계별 치료 규칙표, 의료진 수정·확정, 상담 인계
- 데스크톱·모바일 반응형 UI

## 한계와 안전 경계

- 39장으로 의료진 수준의 진단 정확도를 보장할 수 없습니다. 현재 결과는 **참고사진 유사도 제안**이며 의료진 확정이 필수입니다.
- 촬영 기기·조명·화이트밸런스가 다르면 특징 비교가 큰 폭으로 흔들릴 수 있습니다.
- 흐림, 강한 반사, 색소병변, 낭종, 모낭염, 국소 상처·출혈딸지는 의료진이 분석 대상에서 제외해야 합니다.
- 악화 기간, 모발 수치, 치료 횟수는 기획상 상담 안내값이며 환자 노출 전 의료진 승인이 필요합니다.
- 사례 A/B는 동일 환자의 치료 전후 결과가 아닌 UI 시뮬레이션입니다.

## 레퍼런스 모델 재생성

```bash
python3 tools/build_reference_model.py /path/to/reference-39 .
```

원본 39장은 공개 저장소에 커밋하지 않습니다. 스크립트는 특징 벡터와 단계별 대표 사진만 생성합니다.

## 자동 검증

```bash
node qa-smoke.cjs
```

검증 항목: 실제 파일 업로드, 39장 모델 로드, 대표 사진 분류, 9개 단계, 2~4+ 이미지 고유성, 점수 범위, 치료 매핑, 확정·인계, 모바일 가로 넘침.

## 운영 전 필수 작업

- 서버 인증과 관리자·의료진·상담실장 역할별 권한 검사
- 비공개 이미지 저장소, 만료되는 미리보기 URL, 암호화와 보존기간 정책
- 의료진 승인 기준표·모델 버전·확정 변경 이력과 감사 로그
- 환자 촬영·분석·사례 활용 동의 관리
- 파일 형식·용량의 서버 재검증
